Line following and obsticle detection implementation in a mobile robot

Implementation of a PID algorithm via Arduino IDE for a rover with ultrasonic and infared sensors.

Arduino IDE Robotics

Overview

This project is still a work in progress and the interactive graph will appear in due course. The project bellow was done through following the Mechatronics course (WBIE011-05) at the University of Groningen. The robot itself was pre-made and as students we were tasked with writing and implementing teh Arduino IDE code. The code consists of a PID controller for the infared and ultrasonic sensor.
